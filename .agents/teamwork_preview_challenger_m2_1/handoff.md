## 3. Caveats

- **Python `pass` Scanner**: Python `pass` statement scanner checks line `i-1` for `def` or `class`. If a docstring or comment line intervenes between `def` and `pass`, `validateNonTsFile` will not catch the `pass`.
- **TypeScript Syntax Error Diagnostics**: `ts.createSourceFile()` parses syntactically invalid TypeScript code tolerantly without throwing exceptions. `validateTsAst` does not currently inspect `(sourceFile as any).parseDiagnostics` to flag invalid syntax as `astValid: false`.
- **Review-Only Constraint**: In accordance with challenger rules, implementation files in `src/` were reviewed and tested without modification.
